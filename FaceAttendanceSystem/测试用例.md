# 人脸识别考勤系统测试用例

## 项目概述
本项目是一个基于Flask的人脸识别考勤系统，主要功能包括用户登录注册、人脸录入、人脸打卡考勤、考勤记录查看和管理员用户管理等功能。

## 测试环境要求
- Python 3.10.19
- 依赖包：见requirements.txt
- 摄像头设备
- Microsoft Edge浏览器最新版本
